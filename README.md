AngkaNegeri — Indonesia in Numbers. The country's official statistics from BPS (Statistics Indonesia) gathered in one fast, fully offline site: GDP growth, inflation, open unemployment, poverty, the Gini ratio and the mid-2025 population of all 38 provinces. Every figure is labelled with the period it actually describes, charts are drawn from the same data file the text quotes, and the province table is searchable and sortable. Plain static files — no build step, nothing loaded over the network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or just open `app/index.html` in a browser.
